# Contributing to RamosTech

Thanks for taking a look. Bug reports, fixes and ideas are all welcome.

## Reporting a bug

Open an issue and say what you did, what you expected and what happened instead. Include your macOS or iOS version and the version of the app. If this is the RamosTech repo, say which project folder it is about.

Please leave personal data out of issues: file contents, server or share names, user names, paths that contain your account name, and anything that looks like a password or key. Blur screenshots the same way.

## Suggesting a feature

Open an issue that describes the problem you want solved before you write code. That way we can agree on the approach first and you don't spend time on something that won't fit.

## Sending a change

1. Fork the repository and create a branch for your change.
2. Keep the change to one thing. Small pull requests are easier to review.
3. Open the project folder you are changing in Xcode (each folder has its own README with build notes) and check that the feature you touched still works.
4. Open a pull request that says what changed and why.

## Security problems

Please don't open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md) for how to report it privately.
